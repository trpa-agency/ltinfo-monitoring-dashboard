LT Info Monitoring Dashboard

Program pages, v2 build

This is the Astro rebuild of the program dashboards that embed in the Dashboard card of each program page on monitoring.laketahoeinfo.org. It is built as a spoke of the ESA Ecology design system and themed to the LT Info host. The pages on main stay live until Phase 5 cuts over; this home page stands in until Phase 4 replaces it.

Program pages

One page per program in programs.json, at <category-folder>/<program>.html. Three to start with, one per template:

  • Ozone (O3) Air Quality
  • SEZ Basin-wide Monitoring and Assessment Plan Soil Conservation
  • Tahoe Yellow Cress Monitoring Vegetation Preservation

Host harness: a stand-in for the LT Info Dashboard card, for checking the embed contract (chrome hiding, height posting, 375 px width).
